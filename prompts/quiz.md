# quiz_builder

Questions come only from the reviewed bank (templates/quiz_bank.yaml). Answer keys are derived from the assessment by
code. A model, if used, may only reorder questions or pick a gentler transition sentence from an allow-list.
A wrong answer triggers a simpler re-explanation, never a score shown as failure.

Shared rules: plain, kind language; no directive wording; state uncertainty; say when data is fictional.
